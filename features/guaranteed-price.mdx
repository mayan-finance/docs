---
title: "Guaranteed Price"
description: "The amount quoted is the amount received, on eligible routes."
---

On most cross-chain swaps a quote is an estimate. The user is shown an expected output and a minimum, and the swap settles somewhere between the two. That range is fine for a trade, where a few basis points either way is the cost of doing business.

It does not work for a payment. A merchant cannot display one number and receive another, and a payroll run cannot land short. Guaranteed Price replaces the estimate with a commitment: the output is locked before the swap executes, so the number shown at signing is the number that arrives.

## How it works

<Steps>
  <Step title="Request a quote as normal">
    There is no flag to set and nothing to enable. Mayan determines whether an order is eligible and returns the guarantee on the quote when it is.
  </Step>
  <Step title="Check the auction mode">
    Read `swiftAuctionMode` on each quote in the response. A value of `3` is a Guaranteed Price quote.
  </Step>
  <Step title="Show the locked amount">
    Surface it in your interface so the user knows the number is fixed rather than estimated. On a mode `3` quote, `expectedAmountOut` is the exact amount that will arrive.
  </Step>
  <Step title="The swap settles exact-out">
    The recipient receives exactly `expectedAmountOut`. Not the minimum, not something in between.
  </Step>
</Steps>

## Key concepts

- **Two auction modes, one field.** Swift quotes come back tagged with `swiftAuctionMode`. Mode `2` is an English auction: the user receives at least `minAmountOut` and typically lands near `expectedAmountOut`. Mode `3` is exact-out: `expectedAmountOut` is what arrives.
- **Mayan decides eligibility, not the integrator.** There is no parameter to pass and no allowlist to join. If a quote comes back as mode `3`, the guarantee is available on that order.
- **`minAmountOut` stops mattering.** On an English auction quote it is the floor that protects the user. On an exact-out quote the output is already fixed, so the number to display is `expectedAmountOut`.
- **The guarantee covers the amount, not the timing.** An exact-out order still has a deadline, and an order that no driver fills before it is refunded rather than settled short. See [refunds](/how-mayan-works/refunds).

## Detecting it in a quote

| `swiftAuctionMode` | Behaviour | What to display |
| --- | --- | --- |
| `2` | English auction. Drivers compete and the user receives at least `minAmountOut`. | Both `expectedAmountOut` and `minAmountOut`. |
| `3` | Exact-out. The user receives exactly `expectedAmountOut`. | `expectedAmountOut` alone, presented as a fixed amount. |

Handle both. A pair that returns a guaranteed quote on one order may return an English auction quote on another, so branch on the field rather than assuming a route always behaves one way.

## Supported assets

Guaranteed Price is available on **same-asset transfers of USDC, USDT and ETH**. The input and the output have to be the same one of those three.

It is not restricted by chain. Any pair of supported chains qualifies as long as the asset matches on both sides, so USDC on Arbitrum to USDC on Solana is eligible in the same way as USDC on Base to USDC on Ethereum.

Other assets and cross-asset swaps route through the English auction and settle between the expected and minimum amounts.

## Building with it

The guarantee matters wherever a number is quoted to someone before the money moves.

**Checkout and payments.** A merchant displays a price and receives that exact amount, so the invoice, the confirmation screen and the settlement all carry the same figure. Nothing has to be reconciled afterwards, and no order arrives short. See [Pay](/use-cases/pay).

**Payouts and payroll.** When a business is sending rather than receiving, an exact amount means a recipient is paid what they were promised, not what the market allowed at the moment of settlement.

**Trading and treasury interfaces.** Showing a user a fixed number removes the caveat that usually sits next to a cross-chain quote. The interface can commit to the figure it displays.
