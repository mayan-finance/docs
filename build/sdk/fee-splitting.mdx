A standard integration lists one wallet per network in `referrers`. When the fee on a network needs to go to more than one wallet, list several wallets for that network.

## Setting it up

Pass `referrers` as the second argument to `fetchQuote`, keyed by network type, with a bps share per wallet.

```typescript
const referrers = {
  evm:    [{ address: "FIRST_EVM_WALLET", bps: 10 }, { address: "SECOND_EVM_WALLET", bps: 5 }],
  solana: [{ address: "FIRST_SOL_WALLET", bps: 10 }, { address: "SECOND_SOL_WALLET", bps: 5 }],
};

const quotes = await fetchQuote({ /* ... */ }, { referrers });
```

Pass the same object as `referrerAddresses` at swap time.

## Rules

- **Do not mix the two forms.** The SDK throws if `referrerBps` is set alongside `referrers`, and the quote request fails with `REFERRER_CONFLICT` if `referrer` is.
- **The objects have to match.** The SDK throws at swap time if the object you pass differs from the one the quote was fetched with.
- **POST flow only in the SDK.** `generateFetchQuoteUrl`, which builds a `GET` URL, throws when `referrers` is set. Use `fetchQuote` or `generateFetchQuoteUrlAndBody`.
- **Each list is limited.** A network takes up to 10 wallets, each `bps` is an integer from 0 to 255, and an address can appear only once. A list that breaks these rules, or holds an address that is not valid for its network, fails the quote.
- **Fewer routes are quoted.** A split on the source network is offered on Swift and on same-chain swaps, except same-chain swaps from Solana. MCTP and Fast MCTP pay on the destination network, and are not offered when that network's list holds more than one wallet. The route's maximum rate applies to the total of the split.
- **Use SDK v16.1.0 or later.** On older versions, a `referrers` list is always paid through an address derived from the list, even with one wallet per network, so it is quoted only on Swift and on same-chain swaps that do not start on Solana.
